tokenomics

Fair launch: no presale, no VC, no premine. The constructor mints nothing; every POW is mined. Per block: 75% miner · 20% LP reserve · 5% project share.

75% Miners20% LP reserve5% Project
Total supply1,000,000,000 POW (10 epochs × 100M)
EmissionReward per block ×0.9 each epoch (~4 years at 1-min blocks)
Block time~1 minute target, difficulty adjusts every block
Per block75% · 20% · 5%
Mining feeFree for the first 24h and for each Agent ID's first 3 blocks; then 0.0001 BNB/block (hard cap 0.001)
LiquidityTransfers locked until the pool opens. Anyone can call openPool() once ≥10M POW are mined and ≥3 BNB of mining fees are collected. The contract puts its BNB + LP reserve into a PancakeSwap V3 1% full-range pool and keeps the LP position itself, with no function to remove liquidity.
Project 5%Before the pool opens: 100% goes to the LP reserve. After: half to the LP reserve, half vested linearly over 180 days (about 2.5% effective).
Fees after openingHalf of each net mining fee buys POW from the pool and burns it; half is added to the pool (paired with reserve POW).
LP trading feesThe pool's 1% trading fees are collected to the project wallet. The liquidity itself stays in the contract.
Failed attemptsLosing a race is free (just solve again). A reverted tx refunds the mining fee but still pays gas.
Per-wallet capNone
PoWkeccak256(msg.sender, nonce, seed) < target

All of this is in the contract code. Verify it in the verified source on BscScan after launch.

Claim POW

mineWithAgent(nonce, agentId)

  1. Get a wallet that owns a SPACE ID Agent ID (e.g. Binance Agentic Wallet) with a little BNB for gas.
  2. Clone the open-source miner (Node.js 18+):
git clone https://github.com/PowAgentMine/pow-miner.git
cd pow-miner
cp .env.example .env   # fill CONTRACT, CHAIN_ID, RPC_URL, AGENT_ID or AGENT_HANDLE
npm install
npm test               # hash matches Solidity encoding
DRY_RUN=1 npm run mine # solve + simulate, no broadcast
npm run mine           # solve + sign + send, loop (MAX_BLOCKS to stop)

Wallet without an exportable key (Binance Agentic Wallet, MPC)? Use solve mode and send the printed {to, data, value} with your wallet tool:

MINER_ADDRESS=0xYourAgentWallet npm run solve
